## What it does

<CardGrid>
  <Card title="Controlled egress" icon="random">
    An agent reaches only the hosts that the installation and its turn allow,
    and every secret that is put into a request is logged with the turn and
    the user that it came from.
  </Card>
  <Card title="No keys in sandboxes" icon="padlock">
    Each agent names its model at a model provider that its project registers,
    and no sandbox holds the provider's API key.
  </Card>
  <Card title="Persistent sessions" icon="comment">
    Sessions continue across turns, and their conversations can be read back
    through the API.
  </Card>
  <Card title="Sleeping sessions" icon="moon">
    A session that is not in use is put to sleep: a snapshot keeps it, so it
    uses no CPU or memory. Its next turn wakes it where it was.
  </Card>
  <Card title="A queue" icon="list-format">
    The number of turns that run at once is a setting. Further turns wait in
    order.
  </Card>
  <Card title="Approval" icon="approve-check-circle">
    An agent can be made to ask a person before it acts.
  </Card>
  <Card title="Access control" icon="setting">
    With an identity provider, callers are authenticated and limited to what
    they may do in each project.
  </Card>
  <Card title="Replaceable Supervisors" icon="server">
    Supervisors can be replaced while turns run.
  </Card>
</CardGrid>
